# Biuro Zaginionych Skarpetek

## Opis projektu

Biuro Zaginionych Skarpetek to humorystyczna, jednostronicowa strona internetowa „instytucji”, która od lat bezskutecznie prowadzi śledztwo w sprawie skarpetek znikających w pralce.

Projekt powstał w ramach zajęć na studiach. Jego głównym celem nie jest sama strona, tylko przećwiczenie pracy zespołowej: korzystania z systemu kontroli wersji Git, tworzenia i przeglądania pull requestów na GitHubie oraz planowania zadań w Trello. Strona jest podzielona na 4 sekcje, a każdą z nich wykonuje inna osoba z zespołu na osobnym branchu.

## Funkcjonalności

- **Sekcja 1 – Nagłówek:** logo biura, menu nawigacyjne z linkami do pozostałych sekcji, hasło przewodnie i przyciski prowadzące do galerii i formularza.
- **Sekcja 2 – Listy gończe:** karty poszukiwanych skarpetek z imieniem, opisem i „nagrodą” za odnalezienie.
- **Sekcja 3 – Statystyki biura:** kafelki z (niezbyt imponującymi) wynikami biura, np. liczbą odnalezionych skarpetek.
- **Sekcja 4 – Formularz i stopka:** formularz zgłoszenia zaginięcia skarpetki oraz stopka strony.
- Responsywny układ, który dopasowuje się do szerokości ekranu.
- Wspólna kolorystyka strony zdefiniowana w zmiennych CSS.

## Wykorzystane technologie

- **HTML5:** struktura strony.
- **CSS3:** wygląd strony, w tym zmienne CSS i Flexbox.
- **Git:** kontrola wersji.
- **GitHub:** repozytorium, pull requesty i code review.
- **Trello:** planowanie i śledzenie zadań zespołu.

## Instrukcja uruchomienia

1. Sklonuj repozytorium:
   ```bash
   git clone <adres-repozytorium>
   ```
2. Przejdź do folderu projektu:
   ```bash
   cd bzs-strona
   ```
3. Otwórz plik `index.html` w dowolnej przeglądarce internetowej, np. klikając go dwukrotnie.

Projekt nie wymaga instalowania żadnych dodatkowych narzędzi ani bibliotek.
Nie jest również wymagany żaden live server.
